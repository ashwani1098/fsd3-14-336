# File system of NodeJs
It allows the js code running outside the brouser and interact directly to operating system
## Common operations on file/folder
-Reading and writting files ->readFile(),writeFile(),appendFile()<br>
-Directory management ->mkdir(),rmdir(),readir()<br>
-Metadata/indormation ->stat(),lstat(),fstat()<br>
-Watching for changes ->watch(),watchFile(),unwatchFile()<br>
-Streaming large files ->createReadStream(),createWriteStream()<br>
-File operations ->rename(),truncate(),unlink(),link(),syslink()<br>
